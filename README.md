# Solar Intelligence

Explainable machine-learning project for next-day solar-resource forecasting using real NASA POWER meteorological data.

This repository is being developed as a reproducible student AI portfolio project. The goal is to compare simple baselines and supervised-learning models using chronological validation, report genuine test metrics, and explain model behavior without overstating what the system can do.

> Project status: active development. Experimental results will be added only after the training pipeline has been run and verified.
